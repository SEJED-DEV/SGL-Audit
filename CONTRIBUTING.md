# Contributing to SGL Audit

Thank you for your interest in contributing to the SGL Audit website!

## Development Process

1. **Fork/Clone**: Create a new branch for your feature or bugfix.
2. **Setup**: Run `npm install` to install dependencies.
3. **Develop**: Make your changes. Ensure code quality and responsiveness.
4. **Translations**: If adding new text, update both `src/dictionaries/fr.json` and `src/dictionaries/en.json`.
5. **Blog**: To add a new blog post, update the array in `src/config/blogs.ts`.
6. **Verify**: Run `npm run build` to ensure everything is working correctly.
7. **Submit**: Create a Pull Request with a clear description of your changes.

## Coding Standards

- Use TypeScript for all components and utilities.
- Use Tailwind CSS for styling.
- Ensure all components are responsive.
- Maintain accessibility standards (ARIA labels, semantic HTML).
